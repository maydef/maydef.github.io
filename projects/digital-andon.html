IIoT · TPM · DIGITAL ANDON

Digital Andon & Asset Movement

Sistem panggilan Andon digital terpadu yang menghubungkan stasiun kerja operator, teknisi maintenance, dan supervisor secara real-time — dilengkapi tracking pergerakan aset pabrik berbasis LoRa.

Teknologi & Ruang Lingkup

  • 📡 Node ESP32 + LoRa untuk panggilan Andon nirkabel
  • ⏱️ Logging response time & repair time (MTTR)
  • 📱 Mobile workflow untuk teknisi lapangan
  • 🔗 Integrasi OpenMaint untuk ticketing maintenance
  • 🌐 Express.js REST API & Laravel web dashboard
  • 📍 Asset tracking RFID/LoRa pergerakan antar line

Arsitektur Sistem

andon-architecture 
Operator Button (ESP32/LoRa)
  ↓ Wireless call
LoRa Gateway → API Server
  ↓ Event logging
Database (response_time, repair_time)
  ↓ Real-time feed
Andon Dashboard + Mobile Workflow
  ↓ Alert notification
Supervisor / OpenMaint (ticketing)

Engineering Outcome

Histori event operasional yang terstruktur memungkinkan analisis preventif dan sebagai dasar AI-assisted maintenance di masa depan. Sistem ini secara signifikan mempersingkat waktu respon downtime dan menyediakan data akurat untuk pelaporan KPI maintenance.
