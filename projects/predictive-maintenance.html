PREDICTIVE MAINTENANCE

Smart Machine Predictive Maintenance

Machine-condition monitoring using vibration, pressure and machine-state signals to identify abnormal patterns and support predictive maintenance.

Technology & scope

  • WTVB01-485 vibration sensor via Modbus RS485
  • 100-bar pressure sensor
  • Optocoupler machine-state signal
  • ESP32 + LoRa
  • Raspberry Pi gateway
  • Laravel + Express.js

Architecture

Machine → Sensors → ESP32 → LoRa → Raspberry Pi Gateway → API → Database → Dashboard

Engineering outcome

The system is designed around trend and anomaly visibility rather than a single sensor reading, creating a foundation for condition-based maintenance.
