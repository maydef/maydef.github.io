# Fahmi Andriansyah Portfolio

Static portfolio for GitHub Pages.

## Deploy
1. Repository must be named `maydef.github.io`.
2. Upload all files in this package to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save.
7. Open `https://maydef.github.io`.

## Before publishing
- Replace `your-email@example.com` in `index.html` with the real public contact email.
- Add a CV at `cv/Fahmi-Andriansyah-CV.pdf` if desired.
