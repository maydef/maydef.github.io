Chamber Conveyor Monitoring

Sistem monitoring suhu permukaan obyek bergerak di dalam chamber oven conveyor menggunakan sensor termopile non-kontak dan transmisi nirkabel LoRa untuk memastikan proses curing / drying berjalan pada parameter yang tepat.

Teknologi & Ruang Lingkup

  • 🌡️ Sensor thermopile non-kontak (IR pyrometer)
  • 📡 ESP32 + LoRa untuk transmisi dalam chamber
  • 🔁 Multi-point temperature mapping pada belt conveyor
  • ⚠️ Alarm otomatis saat suhu out-of-range
  • 📊 Dashboard monitoring real-time berbasis web
  • 🖥️ Penyimpanan histori suhu per batch produksi

Arsitektur Sistem

chamber-monitoring-arch 
Object Surface (conveyor belt)
  ↓ Non-contact IR sensing
Thermopile Sensor Array
  ↓ I2C / Analog signal
ESP32 Node (inside chamber)
  ↓ LoRa RF (through walls)
LoRa Gateway (outside)
  ↓ REST API
Database + Web Dashboard
  ↓ Alarm engine
Operator Alert System

Engineering Outcome

Pemantauan suhu permukaan yang akurat dan berkelanjutan memungkinkan tim Quality Control untuk memastikan setiap produk melewati proses curing pada suhu yang tepat. Histori data mendukung analisis traceability dan SPC (Statistical Process Control).
