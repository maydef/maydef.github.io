Chamber Conveyor Monitoring

Monitoring of object surface temperature on a chamber conveyor to improve process visibility.

Technology & scope

  • Temperature sensing
  • ESP32 / LoRa
  • Wireless data transmission
  • Laravel dashboard

Architecture

Temperature Sensor → ESP32/LoRa → Gateway/API → Database → Dashboard

Engineering outcome

Wireless monitoring reduces the need for manual readings and provides historical process data.
