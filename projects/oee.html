OEE — Computer Stitching

An Industrial IoT OEE system designed to make machine availability, production output and quality visible through connected shop-floor data.

Technology & scope

  • Optocoupler for motor session / availability
  • RFID pallet stickers for production identification and standard cycle time
  • IR counter for NG/reject detection
  • Raspberry Pi 4 edge device
  • Express.js API and Laravel dashboard

Architecture

Machine → Sensors/RFID/IR → Raspberry Pi 4 → Express.js API → Database → Laravel Dashboard

Engineering outcome

Availability = motor session. Performance is derived from actual output versus expected output. Quality is based on good output versus total output; OEE combines the three dimensions.
